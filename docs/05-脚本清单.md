# 05 · 脚本清单

> 28 个被跟踪的 Python 脚本，按**位置**分四类。跑之前先看这张表。

---

## 📁 目录约定（2026-09-14 整理后）

| 位置 | 放什么 | 谁在用 |
|------|--------|--------|
| **根目录** | 日常入口 + 共享库 + 页面必需资源 | 你每天敲的命令就在这层 |
| **`tools/`** | 活跃但**非日常**：月报、周报、迁移、归属文档生成 | 换月 / 做周报 / 改归属时才跑 |
| **`archive/`** | **已结项 / 已取代**，不参与任何流程 | 只在要重出旧报告时翻出来 |
| **`sales_analysis/`** | 数据链路的两个脚本（与页面/数据同目录） | `run_all.py` 调它 |
| **`_artifacts/`** | **可再生的中间产物**（`ui_check.py` 的截图快照、历史 xlsx 输出） | 不是代码，可随时删 |

> ⚠️ **不要用 `git add -A`**：`_vw.py`、`gen_watch_compare.py`、`直播间销量汇总工具.html` 是别人的未跟踪半成品。
> `_artifacts/` 与 `archive/` 同理——按文件名精确 add。

## 🟡 `tools/` · 活跃但非日常

| 文件 | 职责 | 入口 |
|------|------|------|
| `gen_room_docs.py` | **归属文档生成器**：`team_config.py` → `docs/03` + `直播间分类.md` + `直播间服务商汇总.md` | `python tools/gen_room_docs.py [--check]` |
| `generate_september_summary.py` | 9月月报，**兼换月模板** | `python tools/generate_september_summary.py` |
| `generate_june_summary.py` / `july` / `august` | 各月月报 | `python tools/generate_<月份>_summary.py` |
| `gen_weekly_report.py` | 周报 xlsx（数值硬编码） | `python tools/gen_weekly_report.py` |
| `migrate_reclassify.py` | 改过 `team_config` 后**回溯重算**历史归属 | `python tools/migrate_reclassify.py [--apply]`，⚠️ 会改写 `history.json` |
| `generate_headphone_report.py` | 耳机专报页 | `python tools/generate_headphone_report.py` |

> ⚠️ **这些脚本都住在 `tools/`，项目根是上一级**。它们的顶部统一是：
> ```python
> ROOT = Path(__file__).resolve().parent.parent
> sys.path.insert(0, str(ROOT))     # ← 少这一行就会 ModuleNotFoundError
> DATA_DIR = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
> ```
> 其中 `gen_weekly_report.py`、`generate_august_summary.py`、`generate_september_summary.py`
> **原先没有 `sys.path.insert`**（靠「脚本目录 = `sys.path[0]`」侥幸工作），搬进 `tools/` 时已补上。
> **复制新月份脚本时必须保留这段**，否则报错会指向 `import team_config`，误导排查方向。
