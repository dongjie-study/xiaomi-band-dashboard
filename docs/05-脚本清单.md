## 🟢 活跃（每日流程用到）

| 文件 | 职责 | 入口 | 输入 → 输出 |
|------|------|------|------------|
| `run_all.py` | **订单链路总入口** | `python run_all.py sales <excel> [our_excel]` | Excel → 调 `daily_update.py`，再把产物拷到 `output/` |
| `sales_analysis/daily_update.py` | **订单入库主脚本**（只有这一份，根目录没有） | `python daily_update.py <excel>` | Excel → `history.json` + `b10pro/band11_history.json` + `stats_data.js` |
| `sales_analysis/generate_dashboard.py` | 画 3 张 PNG | 被 `daily_update.py` 函数级 import，**无 `__main__` 守卫** | `history.json` → `dashboard.png` / `room_comparison.png` / `comparison.png` |
| `band11_review.py` | 首销月「算事实 + 存总结」 | `python band11_review.py status\|context\|auto\|add\|validate [日期]` | `history.json` → `daily_summary.json` |
| `generate_band11_target.py` | 生成首销月进度表 | `python generate_band11_target.py` | `history.json` + `daily_summary.json` → 桌面 xlsx |
| `team_config.py` | 归属唯一配置源 | 纯模块 | 被 7 个脚本 import |
| `product_classifier.py` | 商品归一唯一源 | 纯模块 | — |
| `utils.py` / `formatters.py` | 通用工具 / 格式化 | 纯模块 | — |
| `generate_september_summary.py` | 9月月报 + **换月模板** | `python generate_september_summary.py` | `history.json` → `月度总结/九月销量分析.html` |
| `ui_check.py` | UI 改造前后一致性校验 | `python ui_check.py <标签>` | 7 个页面 → `_ui_<标签>_*.png/json` |
