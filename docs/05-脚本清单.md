> 被跟踪的脚本（Python + 数据小管家相关的 JS / Worker）按**位置**分类。跑之前先看这张表。

---

## 📁 目录约定（2026-09-14 整理后）

| 位置 | 放什么 | 谁在用 |
|------|--------|--------|
| **根目录** | 日常入口 + 共享库 + 页面必需资源 | 你每天敲的命令就在这层 |
| **`tools/`** | 活跃但**非日常**：月报、周报、迁移、归属文档生成、悬浮组件注入 | 换月 / 做周报 / 改归属 / 改小管家时才跑 |
| **`archive/`** | **已结项 / 已取代**，不参与任何流程 | 只在要重出旧报告时翻出来 |
| **`sales_analysis/`** | 数据链路的两个脚本（与页面/数据同目录） | `run_all.py` 调它 |
| **`_artifacts/`** | **可再生的中间产物**（`ui_check.py` 的截图快照、历史 xlsx 输出） | 不是代码，可随时删 |
| **`assistant-server/`** | 数据小管家的后端（Cloudflare Worker）+ 3 个端到端测试 | 只在改小管家时进 |
| **`cloudbase-assistant/`** | 小管家的腾讯云备用版（**未部署**） | 一般不用管 |

> ⚠️ **不要用 `git add -A`**：`直播间销量汇总工具.html` 是别人的半成品（`_vw.py`、`gen_watch_compare.py` 已于 2026-09-26 清理移除）。
> `_artifacts/` 与 `archive/` 同理——按文件名精确 add。

> ⚠️ **这些脚本都住在 `tools/`，项目根是上一级**。它们的顶部统一是：
> ```python
> ROOT = Path(__file__).resolve().parent.parent
> sys.path.insert(0, str(ROOT))     # ← 少这一行就会 ModuleNotFoundError
> DATA_DIR = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
> ```
> 其中 `gen_weekly_report.py`、`generate_august_summary.py`、`generate_september_summary.py`
> **原先没有 `sys.path.insert`**（靠「脚本目录 = `sys.path[0]`」侥幸工作），搬进 `tools/` 时已补上。
> **复制新月份脚本时必须保留这段**，否则报错会指向 `import team_config`，误导排查方向。
>
> 📌 **周报 xlsx 复核（本机没有 LibreOffice，skill 的 `recalc.py` 跑不了；也没有微软 Excel）**：
> `_artifacts/verify_weekly_xlsx.ps1 -Path <xlsx> -Expect <自检.json>` 用 `Excel.Application` COM
> （**本机该 ProgID 实为 WPS 表格 ET**）`CalculateFull()` 重算后校验「零公式错误 + 合计行与自检 JSON 一致
> + 占比列 ∈ (0,1]」。**占比列抽查专门用来抓循环引用**——表格软件对循环引用静默算成 0 且不报错误码，
> `SpecialCells` 抓不到。`.ps1` 必须存成 UTF-8 with BOM，且要用
> `powershell -NoProfile -ExecutionPolicy Bypass -File ...` 跑（未签名脚本被策略拦）。
> ⚠️ WPS 的 ET 是**单实例**且会复用用户正开着的窗口：复核脚本里**绝不能 `Application.Quit()`**
> （会连带关掉用户自己的表格），只能 `Workbook.Close()` 本次这一个；否则文件被 ET 占用，
> 之后 `gen_weekly_report.py` 重跑会 `PermissionError: [Errno 13]`。
> 判断是不是 WPS：`Get-CimInstance Win32_Process -Filter "Name='et.exe'"`——没有 `EXCEL.EXE` 就说明是 WPS。
> 解锁办法：`[Runtime.InteropServices.Marshal]::GetActiveObject('Excel.Application')` 拿到运行中实例，
> 只 `Close()` 目标工作簿（脚本末尾已内置这一步 + 占用自检）。

## 🧩 `assistant-server/` + 前端组件 · 数据小管家（2026-09-26 上线）

不是 Python，但属于这个项目，一并登记。**完整维护手册见 `交接说明.md` 第十二节。**

| 文件 | 类型 | 职责 | 什么时候跑 |
|------|------|------|-----------|
| `assistant-widget.js`（根目录） | 前端 | **右下角悬浮小球本体**：Shadow DOM 隔离、零依赖 | 改外观/交互时改它，改完 **`VERSION`+1** |
| `数据小管家/index.html`（模块页） | 前端 | 全屏聊天页，和悬浮球读同一后端 | 改全屏版界面时 |
| `assistant-server/worker.js` | Worker | 后端：提示词、口径规则、6 个查询工具 | 回答不准 / 加新能力 |
| `assistant-server/wrangler.toml` | 配置 | 域名绑定（`routes`）+ KV 命名空间 | 换域名时 |
| `assistant-server/test-widget.cjs` | 测试 | **悬浮组件端到端**（迷你 DOM 桩跑脚本，30 项断言） | 改完组件**必跑** |
| `assistant-server/test-page.cjs` | 测试 | 模块页端到端（10 项） | 改完模块页跑 |
| `assistant-server/test-accuracy.cjs` | 测试 | **对抗性答题准确性**（6 个真实问题 + 本地独立算期望值对账） | 改完提示词/工具跑 |
| `assistant-server/.dev.vars` | 密钥 | 本地 DeepSeek API Key。**已 gitignore，绝不入库** | — |
| `cloudbase-assistant/`（整目录） | 备用 | 腾讯云 CloudBase 版，功能等价、**未部署** | 备用，一般不动 |

```bash
# 三个测试（都在 assistant-server/ 下跑）
node test-widget.cjs      # 悬浮组件 30 项，含真实问答
node test-page.cjs        # 模块页 10 项
node test-accuracy.cjs    # 答题准确性 6 题

# 改完后端要部署才生效
cd assistant-server && npx wrangler deploy
```

> ⚠️ `worker.js` 的提示词是 JS **模板字符串**，里面不能出现反引号 —— 一旦有，整个 Worker 语法错误、接口全线 500。
