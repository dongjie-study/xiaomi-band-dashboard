## 一、导航怎么来的

`index.html` 自身**不含模块数据**，运行时 `fetch('modules.json')` 后调三个渲染函数：

| 函数 | 作用 |
|------|------|
| `renderSidebar(config)` | 填 `#sidebarNav` |
| `renderModuleCards(config)` | 填首页卡片 `#moduleGrid` |
| `buildModuleRegistry(config)` | 建全局 `modules` 注册表 |

**加/改模块只需改 `modules.json`，不用动 HTML。**

## 三、CSS

| 文件 | 被谁引用 |
|------|---------|
| `theme.css` | `index.html`、`sales_analysis/index.html`、`主播业绩/业绩demo.html`、`月度总结/*`（4 页）、`违规情况/report.html` |
| `common.css` | `index.html`、`sales_analysis/index.html`、`主播分析/index.html`、`主播管理/话术模块.html`、`竞争方案/strategy.html`、`运营工具/gsv.html` |

- 子目录页面用 `../theme.css`，且**必须放在该页自己 `<style>` 之前**
- **`common.css` 不要动**——`theme.css` 才是新页面的令牌来源
- 完全不引任何 CSS 的页面：`hub.html`、`节点总结/*`（3 页）、`耳机专报/*`、`全域or乘方/*`、`违规情况/*考试.html`

## 四、🚨 改样式前必看的硬约束（红线）

**这些选择器/id 被 JS 依赖，动了就白屏或数据错位。**

| 页面 | 绝对不能改 |
|------|-----------|
| `index.html` | `.sidebar-nav > a` 必须是**直接子元素**（JS 用 `>` 选 `.active` / `.expanded`）；`#overview` 内 4 张 `.stat-card` 的**顺序和数量**（JS 按 `[0]~[3]` 硬索引）；全局函数名（内联 `onclick` 引用） |
| `主播业绩/业绩demo.html` | `#filterPanel .filter-btn.active`；`#anchorMonthlyStatsPanel` 的 **9 列表头** + `table-layout:fixed`；35 个 id 目标 |
| `sales_analysis/index.html` | `.prow` `.rrow` `.collapsed` `.hidden` `.extra-row` `.tab-prodroom` `.roomdet-panel` |
| `月度总结` 四页 | id 由生成器产出，**改样式要改生成器**，只改 HTML 会被重跑覆盖 |
