## 三、这个项目的三条铁律

1. **两条流程不许互相污染**
   订单流程只碰 `sales_analysis/`；业绩流程只碰 `主播业绩/业绩demo.html`。
2. **`git add` 要列文件名，禁止 `git add -A`**
   工作区常年躺着别人的半成品（`直播间销量汇总工具.html`）。
3. **脚本生成的文件，改 HTML 无效**
   改样式必须改生成器 `.py`，否则下次重跑覆盖（清单见 [`04-页面与模块.md`](04-页面与模块.md)）。

## 四、目录约定（2026-09-14 整理）

| 位置 | 放什么 |
|------|--------|
| **根目录** | 日常入口脚本（`run_all.py` / `band11_review.py` / `generate_band11_target.py`）、共享库（`team_config.py` / `product_classifier.py` / `utils.py` / `formatters.py`）、页面必需资源（`index.html` 入场展示页 / `workbench.html` 工作台 / `theme.css` / `common.css` / `modules.json` / `xiaomi-logo.png`） |

| **12 个页面目录** | ⚠️ **不能移动**——公开 URL、`modules.json`、各页 `../theme.css` 都依赖现有路径 |

## 五、维护这个知识库

```bash
python tools/gen_room_docs.py           # 归属文档重新生成（改过 team_config.py 后必跑）
python tools/gen_room_docs.py --check   # 只检查是否过期，退出码 1 = 过期
python tools/inject_widget.py           # 悬浮小管家注回各页面（改了组件 / 跑了页面生成器之后）
python tools/inject_widget.py --check   # 只检查哪几页掉了，不写文件
```

- `docs/03` 和 `直播间分类.md`、`直播间服务商汇总.md` 里的机械表格**都是自动生成的**，
  手改会在下次重跑时丢失。要改归属 → 改 `team_config.py` → 重跑脚本。
- `docs/` 下其余文件（01/02/04/05/06）是**手写维护**的，直接改。
- 页面里那行 `<script src="assistant-widget.js?v=N">` 同理 —— 由注入脚本统一维护，**不要手改**；
  改了 `assistant-widget.js` 要把 `VERSION` 加 1 再注入（详见 [`04-页面与模块.md`](04-页面与模块.md) §六）。
