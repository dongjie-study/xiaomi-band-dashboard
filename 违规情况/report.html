❗️❗️❗️ 高发违规 — 平台严查重点汇总（9月更新）

以下违规类型近期频发，基本申诉不回来，请务必传达至所有直播间运营及主播

🔥
降温 / 省电 / 节能 / 终身质保
降温省电节能终身质保
老生常谈的问题，但仍有商家在详情页呈现、主播口述中使用此类话术。平台严查且申诉不回来。
📢
假一赔三 / 质保X年 / 只换不修 / 全国联保
假一赔三质保X年只换不修全国联保
此类承诺类话术，详情页需要明显标注出来，且与口播或直播页面展示完全一致。6月在手表类直播间持续高发，申诉不回来。
📦
送货上门 / 运费险
送货上门运费险送货到家
包邮 ≠ 送货上门/送货到家，运费险 ≠ 来回不需要出运费。正常说"包邮"和"有运费险"即可，不要过度承诺。此类基本也申诉不回来。
🆕
诱导互动（6月新出现）
诱导互动引导评论利益诱导
6月小米官旗手表直播间出现2次诱导互动违规。以抽奖、赠送、利益回馈等方式诱导用户评论/点赞/关注的行为被平台判定违规。此类基本申诉不回来。抽奖/赠品活动必须使用平台福袋工具。
🔧 行动项：所有直播间禁止使用"扣1抽奖""评论抽""点赞送"等诱导话术，统一使用平台福袋工具。
🆕
不当竞争（6月新出现）
贬低竞品不当比较负面评价
6月25日小米官旗手表直播间因不当竞争被预警。直播中贬低第三方同类产品，或对某同类产品表达负面评价被判定违规。避免在直播中对比友商产品时使用贬低性语言。
🔧 行动项：话术培训：对比竞品时只说自身优势，不做竞品负面评价。
🆕
款式/颜色/图案/形状不符（6月新出现）
款式不符宣传图与实物不符
6月23日小米官方手表直播间出现款式/颜色/图案/形状不符违规。直播中宣传的产品款式/颜色与商品详情页展示不一致。确保直播画面中展示的产品与详情页完全一致。
🔥
违规买赠（7月爆发，最高优先级）
买赠活动有条件赠品评论送关注送备注送
7月违规买赠爆发5次，覆盖手环/手表/耳机/官旗全部4个直播间。核心问题：主播使用"扣字送""评论备注""关注加粉送"等有条件赠品话术，平台严查此类诱导行为。2次申诉失败、2次超时未申诉。基本申诉不回来。
🔧 行动项：所有直播间禁止任何形式的"有条件赠品"话术。赠品必须无条件、且提前在商品详情页明确标注。统一使用平台福袋工具。
🆕
门店验货/鉴真服务（7月新出现）
门店查验线下鉴真专柜验货
7月4日小米官方手表直播间因宣传"去附近小米店/小米之家让店员帮你查验"被判定为售后服务不符（虚假宣传）。实际品牌门店/线下专柜无鉴真验货服务，此类表述属于不实宣传诱导购买。申诉失败。
🔧 行动项：所有直播间禁止使用"去门店验货""线下鉴真""专柜查验"等表述。除非确认门店确实提供该服务，否则不得承诺。
🆕
终身质保 / 永久质保 / 终身保障（7月新触发）
终身质保永久质保终身保障绝对化承诺
7月小米官旗手表直播间2次因"终身保障"/"终身质保"被判定售后服务不符。平台认定此类为绝对化承诺，涉嫌虚假宣传。1次申诉成功（已撤销）、1次超时未申诉。此类可尝试申诉但不要抱有侥幸心理。
🔧 行动项：禁止使用"终身""永久""永远"等绝对化词汇描述售后服务，统一使用具体的质保期限（如"1年官方质保"）。
🧪
杀菌 / 抗菌 / 除螨
杀菌抗菌除螨
详情页必须标注检验报告，有检测报告但未在详情页标注也不行。此类可拿着质检报告尝试申诉。
⚠️
劣质 / 低质 等判罚
劣质低质消费者投诉
基本原因是消费者投诉到平台造成。解决办法：尽可能处理好消费者的诉求，避免升级投诉对店铺造成影响。
💰
千川侧新规 — 素材价格与产品不符
千川价格不符12分严重违规
素材里说的价格和产品不符，目前判12分严重违规，大家规避下素材。
🔧 行动项：所有在投千川素材，安排一次价格一致性排查，确保素材标价与实际售价完全一致。
🆕
广告极限用语（8月新出现）
极限词最/第一/唯一不支持申诉
8-9月小米官旗手表直播间出现2次（7.30、8.7）。描述/展示商品时使用广告极限用语，平台标记不支持申诉。
常见雷区：最（最好/最强/最便宜）、第一（销量第一/行业第一）、唯一、顶级/极致/绝对/永久/100%、国家级/世界级等。
🔧 行动项：话术脚本建立极限词黑名单，直播前逐条排查；已使用"最强续航""销量第一""绝对不卡"等表述的，立即替换为具体参数（如"续航14天"）。
🚨
违规营销 — 抽奖玩法致大规模退款（8-9月新出现，性质最严重）
违规抽奖大规模退款支付退款高风险
8-9月出现2次：9月6日小米官方手环直播间、9月23日小米官旗手表直播间。平台原文为"违规宣传抽奖玩法，且导致用户大规模支付退款"。
这是本报告周期内唯一直接牵连用户资金流的违规类型，会造成支付退款率飙升、店铺体验分下滑，性质重于普通话术违规。
🔧 行动项（最高优先级）：① 抽奖必须使用平台官方福袋工具，禁止自建抽奖规则；② 抽奖规则、开奖时间、奖品数量必须与商品详情页完全一致；③ 排查现有抽奖玩法是否存在"先拍后退"设计，立即下线。

关键发现（9月更新）

  • 累计违规63次，涉及6个直播间，有效违规59次（扣除4次已撤销）
  • 小米官旗手表直播间累计最多（16次/25%），其次小米官方手表（15次/24%）、官方耳机直播间（12次/19%）
  • 售后服务不符仍是最突出问题（21次/33%），承诺"终身质保""全国联保"等话术反复触发
  • 赠品活动信息与宣传不符次之（16次/25%），赠品未在商品详情页体现或与详情页不一致
  • 违规买赠9次、诱导互动7次，长期存在未收敛
  • 🆕 8-9月新增违规21次（7.30-9.24，约57天），日均0.37次，与7月持平
  • 🆕 8-9月最集中的是赠品活动信息与宣传不符（7次），5个直播间全覆盖
  • 手表类直播间（官方手表15 + 官旗手表16）合计31次/49%，持续为违规重灾区
  • 🆕 8-9月出现两种新形态：广告极限用语（2次，平台标记不支持申诉）、违规营销（2次，抽奖玩法致用户大规模支付退款）
  • 🆕 诱导互动8-9月再触发4次，说明此前的话术整改未落地
  • 🆕 本批21条源表未提供处置级别，其中2条平台标记"不支持申诉"、1条"待申诉"，其余申诉状态未知
  • 处罚升级路径：警告 → 冻结佣金5% → 冻结佣金15% → 关闭商品分享 → 提升保证金至3000元

整改建议（9月更新）

  1. 🆕 违规营销（抽奖致退款）专项排查（最高优先级）：9月2次抽奖玩法致用户大规模支付退款，直接牵连资金流与体验分。立即排查所有直播间的抽奖玩法，规则必须与详情页一致，且只用平台官方福袋工具
  2. 🆕 赠品信息一致性专项（8-9月最大雷区）：赠品活动信息与宣传不符8-9月触发7次、覆盖5个直播间。上架赠品活动前必须逐条核对详情页，口播/画面/详情页三者一致
  3. 🆕 广告极限用语黑名单：官旗手表8月2次因极限用语被判，平台标记不支持申诉。话术脚本建立黑名单（最/第一/唯一/顶级/极致/绝对/永久/100%），直播前逐条排查
  4. 🆕 诱导互动整改回炉：8-9月再触发4次（手环官旗2次、官方手表1次、官旗手表1次），说明既有整改未落地。严禁"点关注加急发货""扣1抽奖""评论抽""点赞送"等话术
  5. 规范售后话术：不得在未确权情况下承诺"全国联保""终生售后""一年质保""终身保障""无忧质保"，禁止"终身/永久/绝对"等绝对化表述，统一改用具体期限
  6. 禁止违规买赠：严禁任何"扣字/评论/关注/加粉→送赠品"的有条件赠品话术，赠品必须无条件且提前明示在详情页
  7. 🆕 官旗手表直播间重点整改：累计16次居首，8-9月再增6次（极限用语2、赠品2、买赠1、诱导互动1），需立即建立合规话术体系
  8. 🆕 官方手环直播间重点整改：累计10次，8-9月新增5次且出现抽奖致退款，需重点监控
  9. 禁止"去门店验货/鉴真"类话术：不要说"去附近小米店/小米之家让店员帮你查验"，实际门店不提供该服务，被认定为虚假宣传
  10. 🆕 申诉状态跟踪：本批21条仅3条标注了申诉状态，其余未知。需专人核对后台申诉结果并回填数据，避免错过申诉窗口
  11. 建立审核机制：每场直播前对文案/口播脚本进行合规审核，重点审查赠品话术、售后承诺、极限词
  12. 定期合规培训：建议每月1次违规案例分析会，将最新违规类型（尤其极限用语、抽奖玩法）及时传达给所有运营和主播
